# 🐕 Whippet's Countryside Adventure

A fun 2D open world game where you play as a speedy whippet dog exploring the beautiful UK countryside!

## 🎮 How to Play

1. Open `index.html` in any modern web browser
2. Click "Start Game" to begin
3. Collect all the bone treats scattered across the countryside!

## 🕹️ Controls

| Key | Action |
|-----|--------|
| Arrow Keys / WASD | Move left/right |
| Space / Up Arrow / W | Jump |

## 🌟 Features

- **Beautiful UK Countryside**: Sunny skies, rolling hills, trees, flowers, and birds
- **Whippet Character**: White with brindle spots, complete with running animations and wagging tail
- **25 Bone Treats**: Collect them all to win!
- **5 Power-ups**: Grab the golden stars to become shiny and run/jump faster
- **Fallen Tree Obstacles**: Jump over logs blocking your path
- **Parallax Scrolling**: Multi-layered background for depth
- **Particle Effects**: Sparkles when collecting items

## 🎯 Objective

Explore the 4000-pixel wide open world and collect all 25 bone treats. Use power-ups strategically to reach high places and move quickly!
